# 맵 생성 규칙

기획.md의 게임 규칙(중력 변환, 블럭 상호작용, 코인 수집, 웅크리기)을 전제로 한다. 새 스테이지를 만들기 전에 기획.md의 "게임 규칙" 섹션을 다시 확인할 것.

## 필수 조건

1. **밀폐 구조**: 스테이지는 기본적으로 사방이 막혀 있어야 한다. 이 게임에는 사망/추락 판정이 없으므로, 플레이어가 맵 경계 밖으로 나가거나 갇혀서 되돌아올 수 없는 상황이 생기면 안 된다.
2. **해 존재 보장**: 반드시 클리어 가능한 경로가 최소 1개 존재해야 한다. 중력을 4방향(상/하/좌/우)으로 회전시키며 도달 가능한 위치를 따라가 봤을 때 코인을 모두 모으고 포탈에 도달하는 경로가 있는지 직접 시뮬레이션할 것. 확신이 없으면 map-testing 스킬로 검증한다.
3. **과도한 난이도 금지**: 프레임 단위 타이밍, 픽셀 단위 정밀 조작을 요구하는 배치는 피한다. 퍼즐의 핵심은 "어떤 순서로 중력을 돌리고 블럭을 옮길 것인가"에 있어야 하며, 조작 난이도로 어렵게 만들지 않는다.
4. **블럭 오브젝트 용도**: 상호작용 블럭(회색 블럭)은 발판/디딤돌로 밟고 올라가는 용도로 배치한다. 블럭 없이는 도달 불가능한 구간에만 블럭을 두어, 블럭 사용이 퍼즐의 필수 요소가 되게 한다.
5. **공중 중력회전 제약**: 플레이어는 공중에 떠 있는 동안 중력을 회전할 수 없다(기획.md 규칙). 착지 상태에서만 회전 가능하다는 전제로 발판 배치를 설계할 것 — 회전이 필요한 지점 바로 앞에 반드시 착지 가능한 바닥이 있어야 한다.

## 코인 배치

- 스테이지당 코인 개수는 1~5개.
- 코인끼리 서로 인접(반경 2타일 이내)하게 배치하지 않는다. 최소 3타일 이상 간격을 둔다.
- 코인이 블럭 뒤/아래에 가려져 영구히 회수 불가능한 위치에 놓이지 않도록 주의한다. 코인은 중력 영향을 받지 않고 자리에 고정되므로(기획.md 규칙), 배치된 자리 자체가 곧 최종 위치임을 감안해 접근 경로를 함께 설계한다.

## 스테이지 형태

- 정사각형에 가까운 형태보다는 가로 또는 세로로 길게 뻗은 형태로 설계한다.
- 스테이지가 진행될수록 난이도가 점진적으로 상승하도록 순서를 배치한다(스테이지는 순차적으로 열림).

## 산출물 형식

맵 데이터 포맷(그리드 크기, 타일 타입 코드, 블럭/코인/포탈 좌표 표현 방식)이 아직 코드베이스에 정의되어 있지 않다면, 새 포맷을 임의로 만들기 전에 기존 코드(타일 렌더링/충돌 처리 모듈)를 먼저 확인해 기존 관례를 따를 것.
