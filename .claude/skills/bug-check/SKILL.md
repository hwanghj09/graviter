# 버그 체크리스트

## 문법/실행 오류

1. 브라우저 콘솔에서 JS 에러가 발생하지 않는지 확인한다.
2. 기능별로 파일이 분리되어 있는지 확인한다(기획.md 개발 스택 규칙 — 파일 하나에 여러 기능을 몰아넣지 않는다).

## 기획 규칙 대조

기획.md의 다음 규칙과 실제 동작이 일치하는지 하나씩 대조한다:

- 중력 변환: Z키로 시계 방향 90도 회전, 카메라도 함께 애니메이션으로 회전, 들고 있는 블럭의 중력은 변하지 않음.
- 블럭 상호작용: SHIFT로 바라보는 방향 2타일 이내 블럭 1개 잡기/놓기, 든 상태에서 이동속도 20% 감소, 놓으면 블럭 고유 중력 복귀.
- 웅크리기: 히트박스 축소(1칸 틈 통과), 이동속도 20% 감소. 블럭 들기와 동시 적용 시 40% 감소(중첩).
- 코인: 닿으면 자동 습득, 중력 영향 없이 자리 고정.
- 스테이지 클리어: 코인을 모두 모은 상태로 포탈 도달 시 클리어, 자동으로 다음 스테이지 이동.
- 공중 상태에서는 중력 회전 불가.
- 사망/추락 판정 없음 — 맵 밖으로 나가거나 영구히 갇히는 상황이 발생하지 않는지 확인(발생한다면 맵 자체의 버그).
- 저장: 스테이지 클리어 여부, 조작키 변경, 사운드 슬라이더 값이 로컬에 저장되고 새로고침 후에도 유지되는지 확인.

## 회귀 확인

- 변경한 기능과 관련된 다른 기능(예: 블럭 잡기 로직 수정 시 코인 수집·중력 회전과의 상호작용)이 함께 깨지지 않았는지 확인한다.
- 가능하면 실제로 게임을 실행해 해당 스테이지를 플레이해보고 확인한다(정적 코드 검토만으로는 판정할 수 없는 항목).
