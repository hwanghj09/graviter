# 맵 테스트 절차

## 목표

모든 코인을 수집한 상태로 포탈 타일에 도달할 수 있는 경로가 최소 1개 존재하는지 확인한다.

## 검증 방법

1. **상태공간 탐색**: 플레이어 위치 × 현재 중력 방향(4가지) × 수집한 코인 집합 × 들고 있는 블럭 상태를 하나의 상태로 보고, Z(중력 회전)/이동/X(블럭 잡기-놓기) 액션으로 전이 가능한 상태를 BFS 또는 DFS로 탐색한다.
2. **도달 가능성 확인**: 모든 코인을 포함한 상태에서 포탈 위치에 도달하는 상태가 탐색 결과에 존재하는지 확인한다.
3. **제약 조건 반영**:
   - 공중에 떠 있는 상태(점프 중, 낙하 중)에서는 중력 회전 액션을 제외한다.
   - 블럭은 바라보는 방향으로 2타일 이내에서만 잡을 수 있고, 놓으면 블럭 고유의 중력이 적용된다.
   - 웅크리기 상태에서는 히트박스가 줄어들어 1칸짜리 틈도 통과 가능하다는 점을 이동 가능 여부 판정에 반영한다.
4. **코인 수집 순서 무관성**: 코인을 어떤 순서로 모으더라도 최종적으로 전부 수집 가능한지 확인한다(특정 순서로만 풀리는 맵이라면 그 순서가 유일해에 가까운지 점검).

## 난이도 점검

- 탐색된 최단 해가 너무 짧고 단순하면(예: 회전 1~2회로 즉시 클리어) 너무 쉬운 맵일 수 있다.
- 해가 존재하긴 하지만 극도로 좁은 입력 타이밍이나 프레임 단위 정밀도를 요구한다면 map-generation 스킬의 "과도한 난이도 금지" 조건 위반이다.

## 기록

테스트 결과에는 다음을 남긴다: 클리어 가능 여부, 발견된 최단 해의 대략적인 단계 수, 발견된 이슈(도달 불가 코인, 갇히는 위치, 의도치 않은 지름길 등).
